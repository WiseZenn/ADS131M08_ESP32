High-performance Arduino library for the **Texas Instruments ADS131M08** (8-Channel, 24-bit Delta-Sigma ADC), specifically optimized for the **ESP32/ESP32-S3** microcontroller.

> **Key Feature**: This library generates the required 8MHz master clock (MCLK) directly using the ESP32's **LEDC (PWM)** peripheral, eliminating the need for an external crystal oscillator.

## ✨ Features

- **🚀 Programmable Gain Amplifier (PGA)**: Support for 1x, 2x, 4x, 8x, 16x, 32x, 64x, and 128x gain configurations.
  - Enables use with **very low-resistance sensors** and bio-sensors.
  - Software-configurable, no hardware changes needed.
- **⚙️ Oversampling Ratio (OSR)**: Configurable from 128 to 16384, perfect for balancing noise and sample rate (e.g. BLE/WiFi applications).
- **🎛️ Zero Offset Calibration**: Built-in function to dynamically calibrate output at 0V.
- **8-Channel Simultaneous Sampling**: Reads all 8 channels efficiently with strict 30-byte SPI framing.
- **24-bit High Resolution**: Support for full 24-bit (sign-extended to 32-bit) data parsing.
- **Built-in Clock Generation**: Uses ESP32 hardware PWM (LEDC) to generate MCLK.
- **Data Ready Interrupt**: Efficient non-blocking data reading via DRDY pin.

## 🔌 Wiring & Hardware

### Pin Mapping (ESP32-S3 Example)

| ADS131 Pin | ESP32-S3 Pin | Description |
| :--- | :--- | :--- |
| **AVDD/DVDD** | 3.3V | Power Supply |
| **GND** | GND | Ground |
| **MCLK** | GPIO 1 | **Clock Input** (Generated by ESP32 LEDC) |
| **SCLK** | GPIO 12 | SPI Clock |
| **MOSI (DIN)** | GPIO 11 | SPI Data In |
| **MISO (DOUT)**| GPIO 13 | SPI Data Out |
| **CS** | GPIO 10 | Chip Select |
| **DRDY** | GPIO 9 | Data Ready Interrupt |

*Note: Pins are fully configurable in the software constructor.*

## 🚀 Usage

### Basic Example (with Gain, OSR and Calibration)

\\cpp
#include <Arduino.h>
#include "ADS131M08.h"

// Define your ESP32-S3 pins
#define PIN_CLK  1  
#define PIN_DRDY 9  
#define PIN_CS   10 
#define PIN_MOSI 11 
#define PIN_SCLK 12 
#define PIN_MISO 13 

ADS131M08 adc(PIN_CLK, PIN_CS, PIN_DRDY, PIN_MOSI, PIN_MISO, PIN_SCLK);
ADS131M08_Data adcData;

void setup() {
    Serial.begin(115200);
    delay(1000);
    
    if (!adc.begin()) {
        Serial.println("Failed to communicate with ADS131M08! Check wiring.");
        while (1) { delay(100); }
    }
    Serial.println("ADS131M08 initialized successfully!");

    // 1. Set High Gain for small signals (e.g., Load cells, bio-sensors)
    //    The library handles register unlock automatically in begin().
    if (!adc.setGain(ADS131_GAIN_64X)) {
        Serial.println("PGA Gain set failed! Check wiring / power.");
    }

    // 2. Set OSR to reduce output data rate (Crucial for BLE applications!)
    // OSR = 16384 with 8MHz Clock -> Output Data Rate is ~244 Hz.
    adc.setOSR(ADS131_OSR_16384);
    
    // 3. Calibrate offset (Zeroing)
    Serial.println("Calibrating offsets, please wait...");
    adc.calibrate(50);
    Serial.println("Calibration complete!");
}

void loop() {
    if (adc.isDataReady()) {
        if (adc.readData(adcData)) {
            // Print Channel 0 Voltage in millivolts
            float ch0_mV = adc.rawToVoltage(adcData.ch[0]) * 1000.0f;
            
            Serial.print("CH0 (mV): ");
            Serial.print(ch0_mV, 4);
            
            Serial.print("\tCH0 Raw: ");
            Serial.println(adcData.ch[0]);
        }
    }
}
